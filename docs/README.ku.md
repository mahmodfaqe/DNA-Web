# شیکاری DNA

شیکردنەوەی زنجیرەی FASTA بۆ فێرکردن و توێژینەوە، بە کوردی و عەرەبی و ئینگلیزی.

فایلێکی FASTA باربکە، سیستەمەکە ئەمانە دەخاتەڕوو: پێکهاتەی بنکەکان، ڕێژە و لاری
GC، پلەی توانەوە، کێشی مۆلیکولی، چوارچێوە کراوەکانی خوێندنەوە لە هەر شەش
چوارچێوەدا، بەکارهێنانی کۆدۆن، و بەراوردێکی ڕیزکراو کە جێگۆڕکێ لە زیادبوون و
سڕینەوە جیا دەکاتەوە و هەر جێگۆڕکێیەک وەک هاومانا، مانا‌گۆڕ یان بێ‌مانا پۆل
دەکات.

**زمانەکانی تر:** [English](../README.md) · [العربية](README.ar.md)

---

## چوار ئامێر

**شیکردنەوەی زنجیرە** — فایلێکی FASTA باربکە، پێکهاتە، تەرمۆدینامیک، چوارچێوەکانی
خوێندنەوە و بەراوردێکی ڕیزکراو وەربگرە.

**بایۆکۆمپایلەر** — سێرکتێکی بۆماوەیی بە ڕستەیەک باس بکە و دەروازە لۆژیکییەکان،
لیستی بەشەکان و DNA ی دروستکراو وەربگرە. هەمان ڕستە بە کوردی، عەرەبی یان
ئینگلیزی هەمان DNA دەداتەوە، بایت بە بایت.

**بایۆنۆیز-سیم** — ئەو سێرکتەی سەرەوە وا دادەنێت خانە وەک تووشکێک ڕەفتار دەکات.
وا نییە. ئەمە کیمیای ڕاستەقینە دەڕوانێت، کارلێکەر بە کارلێکەر، بەسەر کۆمەڵێک
خانەدا: بورستەکان، بڵاوبوونەوەی نێوان خانەکان، و ئەو تێکەڵبوونەی ئاماژە کە
مۆدێلێکی دەتەرمینی هەرگیز پیشانی نادات.

دوو جین کە هیچ پەیوەندییەکیان نییە هێشتا بە نزیکەی ‎+0.6‎ پەیوەندییان هەیە، چونکە
خانەیەکی دەوڵەمەند بە ڕایبۆسۆم زیاتر لە هەردووکیان دروست دەکات. پیشاندانی ئەو
ژمارەیە لەگەڵ ئەوەی فاکتەرە هاوبەشەکەی لێ دەرکراوە، مەبەستی ئەم تابەیە.

**دیپبایۆ-میمۆری ئارکیتێکت** — خانە دەبێت بیتێک لەکوێ هەڵبگرێت؟ دەتوانێت لە
چڕی پرۆتیندا بژی یان لە خودی DNA دا، و هەموو شتێکی تر لەو یەک هەڵبژاردنەوە دێت.
هەردوو پێکهاتەکە هەر جارێک مۆدێل دەکرێن و ئەوەی دۆڕا بە تەواوی پیشان دەدرێت،
چونکە پێشنیارێک تەنها کاتێک دەپشکنرێت کە ئەوەی بردوویەتییەوە دیار بێت.

پرۆمۆتەرێکی دڵۆپاو دەتوانێت لە ماوەی ٢٤ کاتژمێردا نیوەی کۆمەڵێکی نەهاندراو
بنووسێت — و لەبەر ئەوەی لەناو DNA دا نووسراوە، هەمیشەییە. ئەم تابە ئەوە وەک
ژمارەیەک دەردەخات نەک وەک تێبینییەک.

## پێکهاتەی سیستەمەکە

```
وێبگەڕ ──► DNA-Frontend (Laravel 13) ──► DNA-Backend (FastAPI, Biopython)
                  │
                  └──► MySQL 8 (ئەنجامە هەڵگیراوەکان)
```

| خزمەتگوزاری | ئەرک | کراوە بۆ دەرەوە |
|---|---|---|
| `frontend` | ڕووکار، زمان، هەڵگرتنی ئەنجام، هەناردەکردن | `:8080` |
| `backend` | شیکردنەوەی زنجیرە، وەرگێڕانی سێرکت، سیمولەیشنی هەڕەمەکی | تەنها ناوخۆیی |
| `db` | ئەنجامە هەڵگیراوەکان | تەنها ناوخۆیی |

باکئێند خزمەتگوزارییەکی هەژمارکردنی پاکە. هەرگیز دەقی مرۆیی ناگەڕێنێتەوە — تەنها
**کۆدی هەڵە** و پارامەتری ڕێکخراو — بۆیە هەموو ئەو وشانەی بەکارهێنەر دەیانبینێت
لە فایلەکانی وەرگێڕانی فڕۆنتئێنددان. بۆ زانینی هۆکارەکەی و چۆنیەتی زیادکردنی
زمانی چوارەم، سەیری [ARCHITECTURE.md](ARCHITECTURE.md) بکە.

## دەستپێکردن

```bash
cp .env.example .env
```

کلیلی ئەپلیکەیشن دروست بکە و لە `.env` دا وەک `APP_KEY` دایبنێ:

```bash
docker compose run --rm --no-deps --entrypoint "" frontend php artisan key:generate --show
```

پاشان `MYSQL_PASSWORD` و `MYSQL_ROOT_PASSWORD` بە وشەی نهێنی خۆت دابنێ، ئینجا:

```bash
docker compose up -d --build
```

<http://localhost:8080> بکەرەوە. ڕووکارەکە بە کوردی دەست پێدەکات؛ `‎/ku` و `‎/ar`
و `‎/en` هەمان پەڕەکان پیشان دەدەن.

ئەگەر `APP_KEY` یان وشە نهێنییەکانی داتابەیس بەتاڵ بن، Docker Compose ڕەت
دەکاتەوە و دەستپێناکات. ئەمە بەئەنقەست کراوە: وەشانی پێشوو بە وشەی نهێنی
ئامادەکراوەوە دەهات، و وشەی نهێنییەکی ئامادەکراو کە کاردەکات، ئەو وشە نهێنییەیە
کە دەگاتە سێرڤەری ڕاستەقینە.

## ڕێکخستن

هەموو شتێک لە ڕێگەی `.env` دادەنرێت. ئەو بەهایانەی شایانی زانینن:

| گۆڕاو | بنەڕەت | واتا |
|---|---|---|
| `APP_LOCALE` | `ku` | زمان بۆ ئەو سەردانکەرانەی هەڵبژاردنیان نییە |
| `MAX_FILE_SIZE` | `10485760` | سنووری بارکردن بە بایت (باکئێند) |
| `MAX_UPLOAD_KB` | `10240` | سنووری بارکردن بە کیلۆبایت (فڕۆنتئێند) |
| `MAX_RECORDS` | `500` | ژمارەی تۆمار بۆ هەر فایلێک |
| `ALIGN_MAX_BP` | `3000` | لە سەرووی ئەمەوە، بەراوردکردن دەگەڕێتەوە بۆ جیاوازی شوێنی |
| `RATE_LIMIT_PER_MINUTE` | `30` | ژمارەی شیکردنەوە بۆ هەر بەکارهێنەرێک لە خولەکێکدا |
| `CORS_ORIGINS` | `http://localhost:8080` | لە بەرهەمهێناندا بیکە بە دۆمەینی خۆت |

با `MAX_FILE_SIZE` و `MAX_UPLOAD_KB` لەگەڵ یەکتر بگونجێن، ئەگەرنا فایلێک لە یەک
پشکنیندا تێدەپەڕێت و لەوی تردا دەکەوێت، بە پەیامێکی کەمتر بەسوود.

## API

خزمەتگوزاری شیکردنەوە لە `/docs` دا خۆی دۆکیومێنت دەکات.

| ئێندپۆینت | مەبەست |
|---|---|
| `GET /health` | زیندووبوون، وەشان، ژمارەی کارە چالاکەکان |
| `POST /api/v1/analyze` | شیکردنەوەی فایلی FASTA، ئەنجامی تەواو دەگەڕێنێتەوە |
| `POST /api/v1/analyze-async` | شیکردنەوە دەخاتە ڕیز، `job_id` دەگەڕێنێتەوە |
| `GET /api/v1/job/{job_id}` | پشکنینی دۆخی کارێکی ناهاوکات |

هەڵەکان هەمیشە ئەم شێوەیەیان هەیە:

```json
{ "error": { "code": "sequence_invalid_chars",
             "params": { "record_id": "gene_1", "characters": ["Z"] } } }
```

## هەڵگرتنی داتا

زنجیرە بارکراوەکان کەرەستەی توێژینەوەن، بۆیە ئەنجامەکان بۆ هەمیشە ناهێڵدرێنەوە:

```bash
docker compose exec frontend php artisan analyses:prune --days=30
```

ئەمە ڕۆژانە بە خۆکاری جێبەجێ دەبێت. ماوەکە بگۆڕە بۆ ئەوەی سیاسەتی بەشەکەتان
دەیخوازێت.
