# تحليل الحمض النووي

تحليل تسلسلات FASTA للتعليم والبحث، بالكردية والعربية والإنجليزية.

ارفع ملف FASTA فيعرض النظام تركيب القواعد، ونسبة GC وانحرافها، ودرجة حرارة
الانصهار، والوزن الجزيئي، وأطر القراءة المفتوحة في الأطر الستة جميعها، وتكرار
الكودونات، ومقارنة بالمحاذاة تفصل الاستبدالات عن عمليات الإدراج والحذف وتصنّف كل
استبدال على أنه مرادف أو خاطئ المعنى أو عديم المعنى.

**لغات أخرى:** [English](../README.md) · [کوردی](README.ku.md)

---

## أربع أدوات

**تحليل التسلسل** — ارفع ملف FASTA واحصل على التركيب والديناميكا الحرارية وأطر
القراءة ومقارنة مصفوفة.

**بايوكومبايلر** — صف دارة جينية بجملة واحدة واحصل على البوابات المنطقية وقائمة
القطع والحمض النووي المجمّع. الجملة نفسها بالكردية أو العربية أو الإنجليزية
تنتج الحمض النووي ذاته بايتاً ببايت.

**بايونويز-سيم** — الدارة أعلاه تفترض أن الخلية تتصرف كدورق. وهي لا تفعل. هذه
المحاكاة تتابع الكيمياء الفعلية، تفاعلاً بتفاعل، عبر مجموعة من الخلايا:
الدفقات، والتشتت بين الخلايا، والتداخل الذي لا يُظهره نموذج حتمي أبداً.

جينان لا رابط بينهما البتة يرتبطان بنحو ‎+0.6‎، لأن خلية غنية بالريبوسومات تنتج
المزيد من كليهما. وعرض ذلك الرقم إلى جانب الرقم بعد إزالة العامل المشترك هو
مقصد هذا التبويب.

**ديب-بايو معمار الذاكرة** — أين ينبغي أن تحفظ الخلية بِتاً؟ يمكن أن يعيش في
تركيز البروتينات أو في الحمض النووي نفسه، وكل ما عداه يتبع هذا الاختيار. تُنمذَج
البنيتان في كل مرة وتُعرض الخاسرة بالكامل، لأن التوصية لا تكون قابلة للفحص إلا
إذا ظهر ما تغلّبت عليه.

محفّز متسرّب قد يكتب نصف مجموعة غير محرَّضة خلال ٢٤ ساعة — ولأن الكتابة في الحمض
النووي فهي دائمة. هذا التبويب يُظهر ذلك رقماً لا هامشاً.

## البنية

```
المتصفح ──► DNA-Frontend (Laravel 13) ──► DNA-Backend (FastAPI, Biopython)
                    │
                    └──► MySQL 8 (النتائج المخزّنة)
```

| الخدمة | الدور | منشورة |
|---|---|---|
| `frontend` | الواجهة والتعريب وتخزين النتائج والتصدير | `:8080` |
| `backend` | تحليل التسلسل واستدعاء المتغيّرات | داخليًا فقط |
| `db` | النتائج المخزّنة | داخليًا فقط |

الواجهة الخلفية خدمة حساب خالصة. لا تُرجع نصًا بشريًا إطلاقًا — بل **رموز أخطاء**
ومعاملات مهيكلة فحسب — لذا فكل كلمة يقرأها المستخدم موجودة في ملفات الترجمة في
الواجهة الأمامية. انظر [ARCHITECTURE.md](ARCHITECTURE.md) لمعرفة سبب أهمية ذلك
وكيفية إضافة لغة رابعة.

## البدء

```bash
cp .env.example .env
```

ولّد مفتاح التطبيق والصقه في `.env` باسم `APP_KEY`:

```bash
docker compose run --rm --no-deps --entrypoint "" frontend php artisan key:generate --show
```

اضبط `MYSQL_PASSWORD` و`MYSQL_ROOT_PASSWORD` بقيم من عندك، ثم:

```bash
docker compose up -d --build
```

افتح <http://localhost:8080>. تبدأ الواجهة بالكردية؛ و`‎/ku` و`‎/ar` و`‎/en` تقدّم
الصفحات نفسها.

يرفض Compose الإقلاع إذا كان `APP_KEY` أو كلمات مرور قاعدة البيانات فارغة. هذا
مقصود: الإصدار السابق كان يأتي بكلمات مرور افتراضية تعمل فعلًا، وكلمة المرور
الافتراضية التي تعمل هي كلمة المرور التي تصل إلى الإنتاج.

## الإعداد

كل شيء يُضبط عبر `.env`. أهم القيم:

| المتغيّر | الافتراضي | المعنى |
|---|---|---|
| `APP_LOCALE` | `ku` | لغة الزائر الذي لا تفضيل له |
| `MAX_FILE_SIZE` | `10485760` | حد الرفع بالبايت (الخلفية) |
| `MAX_UPLOAD_KB` | `10240` | حد الرفع بالكيلوبايت (الأمامية) |
| `MAX_RECORDS` | `500` | عدد السجلات لكل ملف |
| `ALIGN_MAX_BP` | `3000` | فوق هذا الحد ترتد المقارنة إلى فرق موضعي |
| `RATE_LIMIT_PER_MINUTE` | `30` | عدد التحليلات لكل عميل في الدقيقة |
| `CORS_ORIGINS` | `http://localhost:8080` | اضبطه على نطاقك الحقيقي في الإنتاج |

أبقِ `MAX_FILE_SIZE` و`MAX_UPLOAD_KB` متوافقين، وإلا اجتاز الملف فحصًا وسقط في
الآخر برسالة أقل فائدة.

## واجهة البرمجة

توثّق خدمة التحليل نفسها على `/docs`.

| النقطة | الغرض |
|---|---|
| `GET /health` | الحياة والإصدار وعدد المهام في الذاكرة |
| `POST /api/v1/analyze` | تحليل ملف FASTA وإرجاع النتيجة كاملة |
| `POST /api/v1/analyze-async` | جدولة تحليل وإرجاع `job_id` |
| `GET /api/v1/job/{job_id}` | استعلام عن مهمة غير متزامنة |

تأخذ الأخطاء دائمًا هذا الشكل:

```json
{ "error": { "code": "sequence_invalid_chars",
             "params": { "record_id": "gene_1", "characters": ["Z"] } } }
```

## الاحتفاظ بالبيانات

التسلسلات المرفوعة مادة بحثية، لذا لا تُحفظ النتائج إلى الأبد:

```bash
docker compose exec frontend php artisan analyses:prune --days=30
```

يعمل هذا يوميًا عبر المجدول. عدّل المدة بما يتوافق مع سياسة قسمك.

## النسخ الاحتياطي

```bash
docker compose exec db mysqldump -u root -p dna_db > dna_db_backup.sql
docker compose exec -T db mysql -u root -p dna_db < dna_db_backup.sql
```

## قائمة تحقق قبل النشر

- [ ] `APP_DEBUG=false` و`APP_ENV=production`
- [ ] `APP_KEY` مولَّد حديثًا لهذا النشر
- [ ] كلمات مرور قاعدة البيانات مغيَّرة عن ملف المثال
- [ ] `CORS_ORIGINS` مقصور على نطاقك
- [ ] `APP_URL` مضبوط على العنوان العام عبر HTTPS
- [ ] TLS يُنهى عند وكيل عكسي أمام `frontend`
- [ ] مدة احتفاظ متفق عليها مع الجهة المالكة للبيانات
