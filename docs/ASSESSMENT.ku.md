## ١. کێشە زانستییەکان

### ١.١ دۆزینەوەی موتەیشن بنەڕەتی هەڵە بوو

**کۆدی پێشوو:**

```python
for i in range(common_len):
    if first[i] != second[i]:
        mutations.append({"type": "substitution", "position": i + 1, ...})
```

ئەمە تەنها کاتێک دروستە کە دوو زنجیرەکە تەنها بە جێگۆڕکێ جیاواز بن. **یەک** بنکەی
زیادکراو هەموو شوێنەکانی دوایی دەخلێنێت.

**پێوانەی ڕاستەقینە** (لە `tests/test_analysis.py` دا وەک تێستی ڕێگری هەیە):

| زنجیرە | ئەلگۆریتمی کۆن | ئەلگۆریتمی نوێ |
|---|---|---|
| یەک بنکەی زیادکراو | **٢٧ جێگۆڕکێ** (هەموویان هەڵە) | **١ زیادبوون**، frameshift، هاوشێوەیی ٩٨.٢١٪ |

بۆ پڕۆژەیەکی بایۆلۆجی، ئەمە جیاوازی نێوان «ئەم دوو جینە هاوشێوەن» و «هیچ
پەیوەندییەکیان نییە»یە. ئێستا Needleman–Wunsch لەگەڵ affine gaps بەکاردێت،
پاشان گۆڕانکارییەکان لە ڕیزکراوەکەوە دەخوێنرێنەوە.

**سنوور:** ڕیزکردن O(n·m) بیرگە بەکاردەهێنێت، بۆیە لە سەرووی `ALIGN_MAX_BP`
(بنەڕەت ٣٠٠٠) دەگەڕێتەوە بۆ بەراوردی شوێنی — **و لە وەڵامەکەدا و لەسەر پەڕەکە
ڕایدەگەیەنێت**. ژمارەیەک کە ڕێبازەکەی شاراوە بێت، ژمارەیەکە کە زیاد باوەڕی پێ
دەکرێت.

### ١.٢ کۆدەکانی IUPAC ڕەت دەکرانەوە

`ALLOWED_BASES = set("ATCGN")` واتای ئەوەیە هەر فایلێکی ڕاستەقینەی NCBI یان
Ensembl کە R، Y، S، W، K، M، B، D، H یان V ـی تێدابێت، ڕەت دەکرێتەوە. ئێستا
وەردەگیرێن، دەژمێردرێن، و لە ستوونی «کوالیتی» دا نیشان دەدرێن.

### ١.٣ Tm بۆ زنجیرەی درێژ واتای فیزیایی نەبوو

`Tm_NN` مۆدێلی دوو زنجیرەی کورتە. بەکارهێنانی بۆ جینێکی چەند کیلۆبەیسی ژمارەیەک
دەداتەوە کە هەڵە نییە، بەڵکو بێ‌مانایە. ئێستا ڕێبازەکە بەپێی درێژی هەڵدەبژێردرێت
و `{value, method, reliable}` دەگەڕێنێتەوە — و خشتەکە ڕێبازەکە لەتەنیشت ژمارەکە
دەنووسێت.

### ١.٤ وەرگێڕان تەنها لە چوارچێوەی یەکەم

`translate(to_stop=True)` تەنها چوارچێوەی یەکەمی زنجیرەی پێشەوە دەخوێنێتەوە. ئێستا
هەر شەش چوارچێوە دەپشکنرێن (٣ پێشەوە، ٣ پێچەوانە) و درێژترین ORF دەدۆزرێتەوە.
جێبەجێکردنەکە لە بواری پرۆتیندایە: هەر چوارچێوەیەک یەک جار وەردەگێڕدرێت (بانگێکی
C لە Biopython) پاشان لەسەر کۆدۆنی وەستان دەبڕدرێت — O(n) لە جیاتی لوپێکی Python.

### ١.٥ زیادکراوەکان

کاریگەری هەر جێگۆڕکێیەک ئێستا پۆل دەکرێت: **هاومانا / مانا‌گۆڕ / بێ‌مانا**. لار
(skew)ی GC، کێشی مۆلیکولی، ڕێژەی AT، و بەکارهێنانی کۆدۆن زیادکران.

## ٢. کێشەکانی پشتگیری زمان

### ٢.١ کێشە بنەڕەتییەکە: پەیامەکان لە Python دا هاردکۆد کرابوون

```python
raise ValueError(f"زنجیرەی {record.id} پیتی نادروستی تێدایە: ...")
```

ئەمە بەتەنها سیستەمە سێ‌زمانییەکە ناتەبا دەکات. پەیامەکە پێش ئەوەی بگاتە
فڕۆنتئێند، پێشتر بڕیاری زمانی لەسەر دراوە.

**چارەسەر:** باکئێند ئێستا **کۆد** دەنێرێت:

```json
{ "error": { "code": "sequence_invalid_chars",
             "params": { "record_id": "gene_1", "characters": ["Z"] } } }
```

و فڕۆنتئێند وشەکان هەڵدەبژێرێت. **زیادکردنی زمانی چوارەم = ٣ فایل لە `lang/` و
یەک دێڕ لە `Locales::SUPPORTED`. سفر گۆڕانکاری لە باکئێند.**

### ٢.٢ ئەوەی نابێت بلووسێتەوە لە RTL

ئەمە ئەو خاڵەیە کە زۆرترین سیستەم لێی هەڵەدەکەن. وەرگێڕان و لۆکاڵایزکردن جیاوازن:

| بەش | ڕەفتار | هۆکار |
|---|---|---|
| تراکی زنجیرە و شوێنەکان | هەمیشە چەپ بۆ ڕاست | زنجیرە ٥′→٣′ دەخوێنرێتەوە. لووساندنەوەی تراکەکە واتە لووساندنەوەی بایۆلۆجییەکە. |
| پیتی بنکە، کۆدۆن، ناسنامەی تۆمار | هەمیشە LTR، مۆنۆسپەیس | `ATG` لەناو دەقی RTL بەبێ `unicode-bidi: isolate` بە پێچەوانە دەردەکەوێت. |
| ژمارەکان | ژمارەی لاتینی، tabular | لە بڵاوکراوەی زانستی کوردی و عەرەبیدا ژمارەی لاتینی بەکاردێت، و tabular ستوونەکان ڕێک دەخات. |

### ٢.٣ فۆنت

Vazirmatn هەڵبژێردرا و **بە کۆد پشکنرا** کە هەموو پیتەکانی سۆرانی لەخۆدەگرێت:
ڕ ڵ ۆ ێ ە ی ڤ گ چ پ ژ — هیچ کەموکوڕییەک نییە. سێلف-هۆست کراوە، نەک لە Google
Fonts، چونکە ئەوە لە کوردستان خاوە.

`ku` لە URL دا بەڵام `ckb` لە `lang` و `hreflang` دا: `ku` زمانێکی گەورەیە کە
کورمانجی و سۆرانی لەخۆدەگرێت، `ckb` تایبەتە بە سۆرانی.

### ٢.٤ پشکنینی خۆکار

- **١٥٥ کلیل × ٣ زمان** — تێستێک هەیە کە دەڵێت هەر سێکیان دەبێت یەکسان بن
- **١١ کۆدی هەڵەی باکئێند** — هەموویان وەرگێڕدراون
- کۆدێکی نەناسراو → پەیامی گشتی + لۆگ (بۆیە هەرگیز `errors.backend.foo` ناخرێتە
  بەردەم بەکارهێنەر)

لەوەی کلیلێکی ئاشکرا بمێنێتەوە.

## ٤. پێکهاتە و کارایی

### ٤.١ فایلێکی ٢٤٦ دێڕی Blade

هەموو شتێک لە یەک فایلدا بوو: HTML، CSS، JavaScript، لۆژیکی PHP، Chart.js.
دابەشکرا بۆ layout + ٤ partial + ٢ کۆمپۆنێنت.

### ٤.٢ Vite دامەزرابوو بەڵام هەرگیز بەکارنەهاتبوو

`resources/css/app.css` بە Vite کۆمپایل دەکرا، بەڵام `@vite` هەرگیز لە Blade
ـەکەدا نەبوو. لەبری ئەوە، Tailwind لە CDN ـەوە دەهات. واتە دوو سیستەمی Tailwind،
هیچیان بەشێوەی دروست.

### ٤.٣ ٤ CDN

| | پێشتر | ئێستا |
|---|---|---|
| CSS | Tailwind JIT لە وێبگەڕدا | ٣٤.٦ KB (٧.٩ KB gzip) |
| JS | ~٣ MB لە ٤ CDN ـەوە | ١.٨ KB |
| فۆنت | Google Fonts | ١٣٥ KB سێلف-هۆست، ٣ subset |
| چارت | Chart.js | SVG ـی سێرڤەر-ڕێندەر |
| PDF | html2pdf (وێنە) | ستایلی چاپ (vector) |

هیچیان version-pinned نەبوون. ئەگەر CDN ـێک بکەوێت، سایتەکە دەشکێت.

### ٤.٤ MySQL هەبوو بەڵام بەکارنەدەهێندرا

ئێستا ئەنجامەکان هەڵدەگیرێن. ئەمە سێ کێشە یەکجار چارەسەر دەکات:
ڕیفرێش دووبارە ئەپلۆد ناکات؛ هەر ئەنجامێک بەستەری خۆی هەیە؛ **گۆڕینی زمان
ئەنجامەکان لەدەست نادات** (پێشتر پەڕەیەکی نوێی GC دەبوو).

### ٤.٥ تراکەکان — گۆڕانکارییەکی بنەڕەتی لە دیزاین

چارتی GC ـی پێشوو هیچی نەدەوت. لە جینەتیکدا **شوێن خۆی دۆزینەوەکەیە**. ئێستا هەر
تۆمارێک ستوونێکی ڕەنگاوڕەنگە (A/T/C/G بەپێی ڕێسای Sanger)، بە پێوانەی درێژی
ڕاستەقینەی خۆی، و ژێرەوەی نیشانەکان شوێنی هەر گۆڕانکارییەک دەردەخەن.

## ٦. ئەوەی تاقی نەکراوەتەوە — پێویستە بزانیت

ژینگەی من PHP ـی هەبوو بەڵام **نە composer، نە Docker، نە وێبگەڕ**. بۆیە:

| شت | دۆخ |
|---|---|
| باکئێندی Python | ✅ ڕۆیشتووە، ٢٤ تێست |
| ڕێزمانی PHP | ✅ ٤٤ فایل، بێ هەڵە |
| ڕێزمان و باڵانسی Blade | ✅ ١٢ قاڵب |
| کلیلی زمانەکان | ✅ ١٥٥×٣ یەکسان |
| بیلدی Vite | ✅ سەرکەوتوو |
| گونجانی داتای باکئێند ↔ ڕوو | ✅ هەموو کلیلەکان هەن |
| **تێستەکانی Laravel** | ❌ نەڕۆیشتوون (composer نەبوو) |
| **بیلدی Docker** | ❌ نەکراوە |
| **ڕوونمای وێبگەڕ** | ❌ نەبینراوە |

**بۆیە هەنگاوی یەکەمت:**

```bash
cd DNA-Frontend && composer install && php artisan test
cd .. && docker compose build
```

ئەگەر هەڵەیەک دەرکەوت، بمنێرە. ئەگەری هەبوونی هەڵەی بچووک لە Blade یان لە
پەیوەندی نێوان کۆمپۆنێنتەکان هەیە، چونکە نەمتوانی بەڕاستی ڕێندەریان بکەم.

## ٧. سنوورە بەئەنقەستەکان

ئەمانە هەڵە نین — بڕیارن، و بەڵگەدارکراون:

- **کۆگای کاری ناهاوکات لە پرۆسێسدایە.** سنووردارە و بەسەردەچێت، بەڵام لەگەڵ چەند
  worker ـێک، کارێک کە بۆ worker ـی A نێردراوە بۆ B نادیارە. چارەسەر: Redis.
  ئێندپۆینتی هاوکات ئەم کێشەیەی نییە.
- **سنووری داواکاری لە پرۆسێسدایە.** بۆ یەک کۆنتەینەر بەسە.
- **بەراوردکردن یەک-بەرامبەر-هەموو.** MSA ـی ڕاستەقینە (MUSCLE، MAFFT) ئامرازێکی
  جیاوازە و دەپێندێنسی زۆر قورستری هەیە.
- **مایگرەیشنە بنەڕەتییەکانی Laravel** (`users`، `cache`، `jobs`) ماونەتەوە.
  بەکارنەهاتوون، بەڵام سڕینەوەیان ڕێگری دەکات لە گۆڕینی `SESSION_DRIVER` بۆ
  `database` دواتر.

## ٨. پێشنیار بۆ داهاتوو

بەپێی پێشەنگی:

1. **تێستەکان بڕۆنە و Docker بیلد بکە** — پێش هەر شتێکی تر
2. **`APP_KEY` بگۆڕە** ئەگەر لە هیچ شوێنێکدا بەکارهاتووە
3. **CI زیاد بکە** (GitHub Actions): `pytest` + `php artisan test` + `npm run build`
   لەسەر هەر push ـێک. ئێستا تێستەکان هەن، بەڵام کەس ناچار نییە بیانڕوات.
4. **مێژووی بەکارهێنەر** — ئێستا «شیکردنەوە دواییەکان» بۆ هەمووانە. ئەگەر
   خوێندکاران بەکاریبهێنن، لەوانەیە نەتەوێت هەرکەسێک فایلی هەمووان ببینێت.
5. **بەراوردکردنی هەڵبژێردراو** — با بەکارهێنەر خۆی هەڵبژێرێت کام تۆمار سەرچاوە بێت
6. **داگرتنی FASTA ـی ORF** — دەرهێنانی پرۆتینەکان وەک فایلی FASTA
